  ## Task 2 — dependency installs are not reproducible                          
                                                                                
  Both `e2e/Dockerfile` and `frontend/Dockerfile` contain:                      
                                                                                
  ```dockerfile                                                                 
  COPY package.json package-lock.json* ./                                       
  RUN npm ci 2>/dev/null || npm install                                         
  ```                                                                           
                                                                                
  Three problems: the `*` glob means a missing lock file is not an error; `||   
  npm install` catches `npm ci`'s failure and re-resolves version ranges, so    
  the                                                                           
  image can be built from dependencies that were never tested; `2>/dev/null`    
  discards the diagnostics that would explain why.                              
                                                                                
  **Known state (confirmed, do not re-investigate):**                           
  `frontend/package-lock.json`                                                  
  exists. `e2e/package-lock.json` does not.                                     
                                                                                
  **First, generate and commit the missing one:**                               
                                                                                
  ```                                                                           
  cd e2e && npm install --package-lock-only                                     
  git add e2e/package-lock.json                                                 
  ```                                                                           
                                                                                
  This resolves and freezes versions from `e2e/package.json`'s ranges once,     
  into                                                                          
  a committed file — it does not touch `node_modules` and does not run the      
  build.                                                                        
  Do not run `npm install --package-lock-only` in `frontend/` — its lock file   
  already exists and is tracked; leave it untouched.                            
                                                                                
  **Then confirm both are actually tracked in git (sanity check, not            
  discovery):**                                                                 
                                                                                
  ```                                                                           
  git ls-files e2e/package-lock.json frontend/package-lock.json                 
  ```                                                                           
                                                                                
  Both paths must be listed. If either is not, stop and report it rather than   
  proceeding — that means the file exists on disk but was never                 
  staged/committed,                                                             
  which defeats the point.                                                      
                                                                                
  **Then, in both Dockerfiles, replace those two lines with:**                  
                                                                                
  ```dockerfile                                                                 
  COPY package.json package-lock.json ./                                        
  RUN npm ci
  ```                                                                           
